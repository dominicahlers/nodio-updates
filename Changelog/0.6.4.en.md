# Nodio 0.6.4

**Release date:** June 2026

External MCP clients and the built-in AI assistant now have clearer guidance for **creating graph connections** via `nodio_create_connection` — not by editing notes. New tools list available **connection type slugs** and let agents define **custom connection types** through the API.

---

## Improvements

- **MCP — connection guidance on connect:** Welcome `instructions` now explain how to create edges, which built-in slugs exist (`references`, `depends_on`, …), and that `nodio_list_connection_types` discovers custom types in the project.
- **New tool `nodio_list_connection_types`:** Returns all built-in and project-defined connection types (slug, label, color, line style) — for MCP and the in-app assistant.
- **New tool `nodio_upsert_connection_type_def`:** Creates or updates a custom connection type (merge-safe, without deleting existing types). Requires **update** permission.
- **AI assistant:** Graph analysis skill and core tools extended for the connection-type workflow; **MCP server** and **AI assistant** help topics updated (DE/EN).
- **@-mentions — custom connection types:** Newly created custom connection types have **@-mention & markdown sync** enabled by default (like built-ins). The mini-toolbar on `nbn:` links lists the same types; the @ picker reloads the type registry when it opens.
- **Project overview — project ID:** A subtle **UUID** appears below each project title (grid, list, archive). The **Properties** dialog includes a **Copy** field for the project ID — handy for MCP, export, and API use.
- **MCP console — complete errors:** Failed tool calls now appear in the activity log with **tool name**, **error message**, and **request payload** — not only in the developer console. Errors, timeouts, and rejections are readable without expanding the entry.
- **Canvas objects — image rotation & styles:** Images and annotated maps can be **rotated** (-45° to +45°) and given **visual styles** in the properties dialog — e.g. Polaroid, Zettelkasten tape, cork board, film strip, blueprint grid, plus filters such as vintage, black & white, cyanotype, and faded. Frame and image rotate together.
- **Canvas map — pin UX:** Place pins with a **two-step flow** (pick a position on the map first, then label and optional note link). Note selection uses the same **combobox** pattern as connections. Pin labels stay **always visible** (pill style like edge labels); the pin list is a **tag cloud** with × to remove.
- **Canvas map — configure pins:** **Right-click** on marker or label (also in the pin list): pick a style (**7 marker variants**), set **marker** and **label colors**, edit label and note link. **Marker and label** are clickable (jump to linked note); **hover** highlights map and list together — without a harsh white outline.
- **Canvas map — pin colors:** Color picker in a **flyout** matching **note** and **group properties** (preview swatch, hex field, palettes, reset).
- **World Canvas — longer preview:** When the graph loads, every note keeps about **100 words** of preview text in memory (up from ~50) — consistent for all cards, regardless of viewport.
- **About — credits & contributors:** New section under **App Settings → About** with appreciative mentions of beta testers and supporters. The list is maintained in Markdown and appears between the developer story and open-source libraries.
- **Dictation — model integrity check (SHA-256):** Speech models are verified against a known checksum after download and before each use. Corrupt models are flagged as **"Corrupt"** in settings and can be re-downloaded with one click — so a faulty model can never be used unnoticed.
- **Sub-canvas — nested levels:** Notes can own **nested canvas levels** (up to **three** depths). Notes with children show a **layer badge** (layer icon + count). **MCP** and the **AI assistant** can create, read, move, and delete content on the root or a sub-canvas level (`parentNodeId`). **In-app navigation** (double-click to enter a level, breadcrumb **World Canvas > …**, Escape to go back) ships when the feature flag is enabled — see **World canvas** help.
- **Interactive tutorial (5 steps):** Guided onboarding on the world canvas — first note via double-click, write text, second note, connection, group. **Quest card** with progress; resume after restart; **Restart tutorial** in Settings.
- **First-run hub:** After the setup wizard, a single **“New to Nodio?”** dialog — start with **template/use case** or the **interactive tutorial** instead of two separate welcome modals.
- **Sub-canvas — remember level per session:** Per project, the last opened **sub-canvas level** including zoom and pan is preserved — when switching to the editor, other areas, or another project and back (until the app restarts).
- **Sub-canvas — UX & dev bypass:** Context menu **Open sub-canvas**; layer badge on empty **canvas container** notes too; Dev Workbench toggle **Sub-canvas navigation**; note type **Canvas container** labeled in search and filters.
- **Level Design template:** New bundled starter under **Create Project → Game Design** — map-first world planning with three region groups, POI notes, `parent_of` / `depends_on` gating paths, canvas map label and location pins, starred Boss Arena (minimap favorite marker), inbox POI sketch, and an MCP-friendly demo graph.
- **API Documentation template:** New bundled starter under **Create Project → Productivity** — linked REST endpoint catalog with schemas, code samples, **Public API v1** group, **Endpoints table** list profile, inbox stub, and MCP-first lookup from Cursor or Claude Desktop.
- **Freelancer Client template:** New bundled starter under **Create Project → Productivity** — one local `.db` per client with Kanban **Client deliverables**, saved views **Client review** / **Internal WIP**, milestone dependencies (`depends_on`), and optional MCP status checks (`kanban-status`, `project-overview`).
- **New Crime Fiction project template:** Showcase deduction graph with 15 demo nodes, **Act I**, **Suspects**, and **Clues** groups, `contradicts` edge between conflicting witnesses, **Manuscript** Kanban, and MCP-first readme — under **Create Project → Narrative & Writing**.
- **Create project — Narrative category:** New gallery tab **Narrative & Writing** for story and writing templates (e.g. Crime Fiction).
- **Import template pack:** Under **Create project**, import templates as a **folder** (with `templateManifest.json`, readme, and preview) instead of a single `.db` only. If no manifest is present, import still succeeds — with a notice that description and gallery preview may be limited.
- **Template Builder — step by step:** The Template Builder guides you through **metadata**, **media**, and **export** in three steps (stepper pattern like the bug reporter).
- **Template Builder — gallery preview:** On export you can optionally pick a **preview image**; it appears in the template gallery instead of the placeholder graphic.
- **About — credits banner:** Contributors scroll horizontally in a news-style ticker directly below the product overview in **App Settings → About** (non-selectable text, vertically centered). **Show all contributors** opens a scrollable detail list with name and contribution — similar to open-source libraries; collapsing brings the ticker back.
- **About — page layout:** **Principles** and **Roadmap** use full width again, stacked vertically; the **Support** section is more compact (intro copy in one card).
- **About — contributors:** The credits list was expanded (including Dardan Rexhepi, Der-Haku-Inu, DeviluDevLP, Phil (Wandelstudios)); roles updated for Eric von Oeson and Nyuchen. The expanded detail view shows **four** entries before scrolling.
- **App Settings — sidebar navigation:** The left sidebar now follows the selected **Chrome color pack** (under **Design**). When a tab is active, **sub-items** expand (e.g. theme, color pack, typography); clicking scrolls directly to that section. While scrolling the content, a **position indicator** highlights the visible section in the sidebar.
- **AI assistant — connection check:** **Connection check** pings the configured provider (Ollama, OpenAI, Gemini, Grok, Anthropic, custom) and shows **latency** or the **error message** — instead of always reporting OK.
- **AI assistant — endpoint URLs:** **Ollama** and **custom endpoint URL** are saved immediately when you leave the field — not only in the draft until **Apply settings**.
- **Shortcuts — keyboard map:** Under **App Settings → Shortcuts**, switch between **List** and **Keyboard map**. The map shows in-app and **global system shortcuts** on a visual keyboard (QWERTY/QWERTZ); hover in the legend or on a key highlights the matching shortcut — both ways. Shortcuts can be rebound and reset directly in the map.
- **Keyboard map — search:** The search field sits above the category tabs and searches **all categories** at once. Matches show a category badge; legend and keyboard glow together.
- **Keyboard map — comfort:** **QWERTY/QWERTZ** is detected automatically from your keyboard layout (manual override remains available and is remembered). Your chosen view (**List** or **Map**) is restored on the next visit. Key combinations in the legend are easier to read; keyboard hover uses a stronger fill tuned for light and dark mode.
- **App Settings — Community & Web:** Discord and the website appear in the sidebar as **compact icons side by side** (official Discord logo, globe for the website) — less vertical space, tooltip on hover.
- **App Settings — setup wizard:** **Start setup wizard** is only visible in **dev mode** (Vite dev build or `devmode.nbn`).
- **App Settings — sidebar height:** The navigation list grows with expanded sub-items (e.g. AI assistant, MCP server) and scrolls only when needed; **Community & Web** sits directly under **About**.
- **Help Center — sidebar navigation:** Under the active topic, **sections** (headings from the help article) expand like App Settings. Click scrolls to the section; while scrolling, a **position indicator** marks what you are reading. **Community** links (Discord, website) appear at the bottom of the sidebar.
- **Help Center — better search:** Search is now **section-aware** with improved ranking — e.g. “note delete” surfaces canvas help before the AI assistant. Results show **topic — section**; a click opens the right spot directly.
- **Help Center — formatted search preview:** Search hits show a **formatted** preview (bold, lists, shortcut keycaps) instead of raw Markdown text.
- **Help — consistent shortcut keycaps and action chips:** Shortcuts render as keycap pills (`shortcut:…`, `kbd:…`); menu actions as colored chips; media footnotes as info callouts instead of blockquote styling — including sketch, time-lapse, and world canvas topics.
- **Help updated (0.6.0–0.6.4):** In-app help (DE/EN) now covers **MCP console**, **auto-approve**, **write preview**, **Whisper/VAD/GPU**, **interactive tutorial**, **first-run hub**, **keyboard map**, **template gallery**, **canvas image/pins**, **Kanban add-node**, and other 0.6.x topics — including seven learning paths in the Help Center.

## Bug fixes

- **MCP popout — no scrollbar flash:** The floating MCP window uses a **fixed height** again; switching between Status and Console no longer resizes the window. Long activity logs scroll inside the tab — no brief visible browser scrollbar.
- **MCP console — export icon:** The activity log export button now uses the same download glyph as main navigation (**Export**), not the fallback question-mark icon.
- **World Canvas — card size with tables:** Notes set to **Medium** or **Large** card size keep their intended height on the board even when the preview contains a Markdown table. Tables render compactly and clip at the bottom instead of stretching the whole card.
- **World Canvas — connection labels above groups:** Type pills on edges (e.g. “References”, “Depends on”) are no longer hidden behind **colored group frames** — they render readable above groups and note cards again.
- **World Canvas — viewport across route changes:** When switching between Canvas, Editor, and other areas, your **last zoom and pan position** is preserved. The canvas no longer jumps back to a previously focused note (e.g. after graph search) when you only briefly opened the editor.
- **Canvas objects — rotation with frame:** Rotated images are no longer clipped inside an axis-aligned frame — **border, style, and image** rotate as one object.
- **Canvas map — upright lightbox:** The large map view (lightbox) does **not** apply board rotation — the map and pins always appear upright for precise pin placement and editing.
- **World Canvas — preview after pan:** Note card text stays visible when you pan away and return later — preview is no longer cleared by deferred visibility logic.
- **World Canvas — PNG export:** Board and saved-view exports show cards with Markdown preview again instead of empty card bodies.
- **Dictation — more precise transcription:** The dictation feature now uses a **Silero VAD model** (Voice Activity Detection) to detect speech pauses instead of fixed 2-second chunks. The transcript is submitted only when a real pause is detected — fewer cut-off words, no chunking artefacts.
- **Dictation — persistent Whisper server (GPU):** On app start, `whisper-server.exe` is launched in the background. The model stays resident in RAM so each utterance transcribes in ~200–400 ms instead of ~3–5 s per segment (no more per-segment model reload). Automatic fallback to CPU when no Vulkan GPU is found.
- **Dictation — GPU selection in settings:** Under **AI assistant → Whisper** you can choose the GPU for transcription (dropdown listing detected Vulkan GPUs). Also configurable: silence threshold (how long a pause before committing a segment) and live preview (toggle partial results during speech).
- **Dictation — no word loss during fast speech:** Multiple speech segments arriving concurrently are now **processed sequentially** (queue) instead of the second segment being silently dropped.
- **Dictation — corrupt model downloads:** A buffer-reuse race during download could produce model files with the correct size but wrong content. Such a model made `whisper-server` allocate huge amounts of RAM (instead of using the GPU). Downloads are now written without corruption and additionally verified by SHA-256; corrupt files are rejected instead of used.
- **World Canvas — double-click handler:** Fixed a console warning about unknown prop `onPaneDoubleClick`; `@xyflow/react` v12 does not expose this prop. Double-click detection is now handled inside `onPaneClick` with a timestamp comparison.
- **First-run hub (legacy INI):** The hub appears without deleting `Nodio.ini` when the interactive tutorial has not been offered yet — no manual config reset required.
- **Interactive tutorial — step 2:** Opening or editing a note no longer immediately redirects you back to the canvas.
- **Interactive tutorial — project start:** Error creating the tutorial project (`NOT NULL constraint failed: node_type_templates.markdown`) fixed — missing default template for the **canvas** note type.
- **App startup:** White screen (splash and main window) fixed — missing translation imports for the **mcpServer** namespace; UI still mounts on i18n init failure with a console error.
- **World Canvas — multi-select & pan:** In multi-select mode, **middle-mouse pan** works again — left-click drag stays reserved for the selection marquee; **Space + drag** was already unchanged.
- **World Canvas — multi-select & pan (selection box):** Middle-mouse pan also works **inside** the blue selection bounding box (gaps between selected items) — left-click still moves the selection there.
- **Template build — re-export:** Re-building a template from a source database that only has embedded media blobs (empty `assets/` folder) no longer fails — the build uses the same disk-then-database hybrid read as at runtime.
- **Canvas map — lightbox startup:** Runtime error opening the large map view (missing module export for pin styles) fixed.
- **Disable MCP:** The toggle under **App Settings → MCP server** now reliably stops the server — previously MCP stayed active in the trail menu because IPC arguments were passed incorrectly.
- **MCP port:** Port changes in the MCP panel are applied correctly again (same IPC fix).
- **App Settings — sidebar hover:** Main nav buttons no longer shift past the right sidebar edge on hover — slightly narrower button width leaves room for the existing slide-in animation.
- **Keyboard map — edge keys:** Highlighted keys at the far left or right (e.g. Esc, Ctrl, Backspace) are no longer clipped at the edge on hover — glow and scale stay fully visible.
