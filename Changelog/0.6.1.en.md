# Nodio 0.6.1

**Release date:** June 2026

Hotfix **0.6.1** fixes an auto-updater issue where beta users were incorrectly offered an older stable version as an update, and stops the Auto Bug Watcher from opening falsely when the app runs in the background.

---

## Bug fixes

- **Auto-updater — no downgrade:** With the beta channel active and no matching beta release on GitHub, electron-updater fell back to `latest.yml` (stable) and offered an **older** version (e.g. 0.5.0) as an update. Cause: electron-updater's `channel` setter implicitly sets `allowDowngrade = true`. Nodio now explicitly sets it to `false`. Additionally, the `update-available` handler ignores feed versions that are not semver-newer than the installed app.
- **Technical:** [`updateService.ts`](../../00__Phase_Source/src/main/services/updateService.ts) — `applyUpdaterChannelSettings()` + semver guard in the event handler.
- **Auto Bug Watcher — no false alarms in the background:** When the main window was not in the foreground, Chromium throttled renderer timers; the heartbeat was no longer sent every 3 s and the Bug Wizard opened with trigger `heartbeat-miss` although the app was healthy. The main window now sets `backgroundThrottling: false` so the renderer heartbeat keeps running reliably.
- **Technical:** [`index.ts`](../../00__Phase_Source/src/main/index.ts) — `createWindow()` `webPreferences.backgroundThrottling: false`.

---

## Note for beta users

For the updater to find **new** beta builds going forward, the release must be deployed to GitHub (`dominicahlers/nodio-updates`) with `beta.yml` — e.g. via `scripts/01__Windows/phase-deploy-beta.ps1`.
