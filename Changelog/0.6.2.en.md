# Nodio 0.6.2

**Release date:** June 2026

Patch **0.6.2** restores the three bundled project templates (GDD, Sprint, Security Concept) in built and installed releases — visible in the “New project” template gallery.

---

## Improvements

- **Release notes:** When showing version notes after an update, Nodio hides an internal technical appendix at the end of the changelog file — only the end-user section remains visible.
- **Kanban: add notes from the board:** Empty columns show a hint card with three actions — create a new node, link an existing note, or connect a canvas group to the board. The board header offers the same menu under **Add node**.

---

## Bug fixes

- **Project templates in shipped builds:** After installation, GDD, Sprint, and Security Concept templates were missing from the “New project” gallery even though they appeared in dev mode. The NSIS installer deleted the bundled `resources/templates` folder on every setup. That delete step is removed; templates are now always embedded.
- **Release notes window:** Text is readable again in dark mode. The node search bar is no longer shown in this window’s title bar.

---

## Note

Existing installations receive the templates automatically after update or reinstall — no manual import required.
