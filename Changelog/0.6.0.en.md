# Nodio 0.6.0

**Release date:** May 2026

Version **0.6.0** bundles the large incremental update (canvas, editor, journal, Kanban, Live-Write, AI assistant with Whisper dictation, and more) with the built-in **MCP server** (Model Context Protocol). External AI clients like **Claude Desktop**, **Cursor**, or **Cline** can access your Nodio knowledge graph directly and locally.

---

## MCP Server (Model Context Protocol)

- **Embedded HTTP server** on `127.0.0.1:7421` (port fallback 7421–7430) — no cloud, no proxy.
- **Bearer token authentication** (`nbn_` prefix, 44 characters, Base64url). Token is generated, shown, and can be copied or regenerated in settings.
- **71 `nodio_*` tools** — read, search, create, update, and delete notes; manage connections and groups; control Kanban boards and journal; use attachments, tags, and export.
- **Write-permission toggles** (create / update / delete / require confirmation) — independently toggleable. Default: read + navigate only.
- **Confirmation dialog** — when write confirmation is enabled, a dialog appears in Nodio before each write action. Times out after **120 seconds** (since v1.3 addendum; previously 60 s).
- **Quick setup**: copy configuration snippets for Claude Desktop, Cursor, and Cline directly from a button in settings.
- **Tray integration**: MCP status (running / stopped / error / disabled), copy token, and open settings directly from the tray context menu.
- **Header quick access**: New `lan` icon in the title bar — shows status indicator, copy token, and link to settings. Visibility controlled by `navModuleVisibility.showMcpServer`.
- **Settings section "MCP Server"**: toggle, status, port, token (show / copy / regenerate), write permissions, and quick setup — accessible via **Settings → MCP Server**.
- **Deep-link protocol** `nodio://`: links from MCP responses navigate directly to notes, projects, or settings in Nodio. Registered as a system protocol handler.
- **Auto-start with Nodio**: optional — MCP server starts automatically when Nodio opens.
- **System boot start**: optional — Nodio (and with it the MCP server) starts at login in the background (system tray).
- **Live resource updates**: when a note changes, connected MCP clients receive a `notifications/resources/updated` notification.
- **7 prompt templates**: `nodio.project-overview`, `nodio.graph-analysis`, `nodio.kanban-status`, `nodio.journal-daily`, `nodio.weekly-review`, `nodio.find-orphans`, `nodio.toon-bundle` — available via `prompts/list` and `prompts/get`.
- **In-app help**: new help documents "MCP Server" (DE/EN) under **Settings → Help**, cross-referenced in the general settings help document.
- **DB migrations**: workspace V13 (`projects.auto_attach_for_mcp`), project V45 (`audit_log.source`).
- **Single-instance lock**: a second Nodio instance is rejected and brings the running window to the foreground.

### MCP Server — Hardening & Cursor integration (v1.3 addendum)

- **Streamable HTTP sessions:** One transport per MCP client session instead of reusing a stateless instance — fixes HTTP 500 (`Stateless transport cannot be reused`) after the first tool call in Cursor, Claude Desktop, and Cline.
- **Server instructions & `_meta`:** On `initialize` (`instructions` field) and `tools/list` (`_meta.nodio`), Nodio reports catalog size, visible tools, and hidden write permissions — clients see permission state without trial and error.
- **Global write confirmation dialog:** `ToolWriteConfirmOverlay` in the app shell — MCP write actions show the confirmation dialog even when the AI chat is closed; Nodio brings the main window to the foreground; **120 second** timeout.
- **Auto-approve bulk MCP writes:** New write-permission option **Auto-approve bulk MCP writes** (`PermAutoApproveBulkWrites`, default off) — mass imports and automation without per-action confirmation; security disclaimer with two-click enable and warning while active.
- **Workspace tools:** `nodio_list_projects` works without `projectId` (workspace-only tool).
- **Live resource updates:** Correct MCP SDK notification API for `notifications/resources/updated` — notification failures no longer break user actions on note changes.
- **List view:** Material icon `viewColumn` registered — no React boundary crash on saved column views (`canvas?list=1`).
- **Dev scripts:** `scripts/mcp-smoke-test.mjs` (instructions, `_meta`, tool calls) and `scripts/mcp-import-dev-docs.mjs` (Markdown tree → canvas with `nbn:` mentions and connections) for local validation and bulk import.

### MCP Server — Welcome, QoL & floating panel (v1.4 addendum)

- **Welcome context on `initialize`:** Dynamic **`instructions`** with a project list (up to 30 entries, `lastOpened`, archive state), **`[CURRENT_IN_UI]`** for the project open in Nodio, and **quick-start** hints with example tool calls.
- **Sessions in the app:** `mcp:listSessions` / **`mcp:sessionChanged`** event — connected clients (name, version from `clientInfo`) in the **MCP quick panel** (header `lan`) and tray status line; **toast** on connect/disconnect.
- **Floating MCP panel** (`?win=mcp`): Always-on-top window from the quick panel (**Open in floating window**), **fixed compact size** (not resizable), **transparent margin** around the card, **drag handle** to move on the desktop, subtle **close** control in the header (hides the window).
- **Main-window control:** **MCP settings** and **Open project** in the popout bring the main window to the front (`navigateMainWindow`) and hide the popout (same pattern as the command palette from the tray).
- **Help (DE/EN):** **MCP Server** topic — welcome context, quick panel, floating window, close button.

## Canvas

- **Viewport backdrop:** In **Project dashboard → Appearance**, set a custom background image or underlay colour for light and dark mode — with fit mode and opacity. The grid stays on top. *Use case:* give each project a distinct visual identity or subtle watermark look.*
- **Undo & redo:** Move nodes, groups, objects, or create connections — then undo with **Ctrl+Z** and redo with **Ctrl+Shift+Z** or **Ctrl+Y**. Toolbar buttons show when history is available. *Use case:* experiment freely on the board without fear of breaking layout.*
- **Multi-select mode:** Press **V** to toggle selection mode, drag a rubber-band box, then group, move, or delete everything at once. Selected group frames become subgroups correctly. *Use case:* reorganise a cluster of notes into a new group in one step.*
- **Multi-select — bulk actions:** When **notes** are selected, the floating toolbar adds **status**, **card colour**, **tags** (add or remove), **archive** (with confirmation), and **PDF (batch)** (up to 50 notes). Changes are saved via batch update (max. **300** notes per operation) — no need to switch to list view. The bar shows **total selection count** and **note card count** separately; **canvas objects** (symbols, images) are excluded from bulk actions. With **group frames** in the selection, a dialog asks whether to include on-canvas notes **inside** those groups (including subgroups and collapsed groups); **archive** still uses a second confirmation afterward. *Use case:* recolour, tag, or export several cards on the board in one step.*
- **Connection storytelling:** Hover a connection line to see from → to, relation type, creation date, and optional label or description. *Use case:* understand at a glance why two notes are linked during a review.*
- **Overlapping connections (hover):** When several connections share the same **visible route** (e.g. **collapsed groups**), the story tooltip no longer shows the topmost single connection — instead **Multiple connections overlapping** and **Left-click for overview**; **left-click** still opens the **Overlapping connections** picker modal. *Use case:* avoid misleading from→to text on stacked edges.*
- **Connection strength:** Set strength **1–5** when editing a connection — stronger links draw thicker and more opaque. *Use case:* distinguish weak references from core relationships in a dense graph.*
- **Graph search:** Results are ranked by relevance, not just recency — the best title or content match rises to the top. *Use case:* find the right note quickly in projects with hundreds of entries.*
- **List view — saved views:** At the top of **list view**, pick **Standard view** or a **saved profile** (**Save**, **Save as new**, **Delete**). **Layout:** **Table** (virtualized, as before), **Gallery** (card grid with type/status and excerpt), or **Cards** (wide rows with metadata). **Columns** in table mode can be shown/hidden and reordered with arrows; **click a column header** toggles sort direction. **Filters:** multi-select **status** and **type**, **Starred only**; sort by title, type, status, created/updated, or **word count** — replaces the fixed “last modified” order. **Graph search** in the title bar still intersects the list. Profiles live in the project DB (`list_view_configs`); edits to the active view are **debounced** to disk. *Use case:* e.g. a “review” gallery filtered by status or a compact table for bulk edits — without reconfiguring every session.*
- **Spotlight fix:** Picking a search hit no longer causes repeated camera jumps or flickering highlights. *Use case:* jump to a note once and stay focused.*
- **Minimap markers:** Starred notes show as amber dots; notes edited in the last 48 hours as green dots. *Use case:* spot favourites and recent work while navigating a large canvas.*
- **Import via inbox:** Markdown import moved into the **inbox drawer** — drop files there or onto the canvas (the drawer opens automatically). Imported notes land in the inbox first. *Use case:* bulk-import a vault, then drag only what you need onto the board.*
- **Insert image from gallery:** When adding an image, choose **Upload new** or **From project gallery** instead of always opening the file picker. *Use case:* reuse assets already in the project.*
- **Collapsed group labels:** Group names appear again as pills beside collapsed circles. *Use case:* identify groups without expanding them.*
- **Connections inside groups:** Lines to cards inside a group are no longer hidden behind the group fill. *Use case:* follow relationships within nested structures.*
- **Canvas time-lapse:** Replay how your project grew from the audit log — play, scrub, auto-follow the camera, and export **WebM** video. Range and speed are configurable. *Use case:* show stakeholders how an idea evolved over weeks.*
- **View slideshow:** Auto-play all saved views in a folder — ideal for demos and walkthroughs. Pause, skip, adjust tempo, or loop from the on-screen HUD. *Use case:* present a project narrative without manual camera moves.*

### Addendum — Note group assignment (group mode)

- **Group mode — new note:** With **group mode** on, creating a note via **New note** (toolbar or shortcut) while its card rectangle **overlaps an open group** assigns it to that group immediately — same rule as drag-and-drop assignment (smallest overlapping group when frames are nested). *Use case:* start writing inside a group without dragging the card afterward.*
- **Note context menu — Assign to group:** For **on-board notes**, **Assign to group…** lists nearby groups (roughly **300 canvas pixels**, edge to edge), sorted by distance; **expand** to see candidates, **hover** to highlight the group on the board. Click assigns membership; **Remove from group** when already assigned. *Use case:* assign via menu instead of drag when the card is already placed.*
- **Shared spatial logic:** Spawn, drag-and-drop, and the context menu use the same detection (AABB overlap or edge distance); **undo** after spawn can preserve group membership.
- **Remove from group — repel & focus:** **Remove from group** (context menu or drag onto empty canvas in **group mode**) **repels** the card outside the group frame (same heuristic as when moving groups). Briefly afterward: **card glow**, **minimap highlight**, and a **ghost-view camera fly** to the note (~1.7 s); with **reduced motion**, glow and minimap only. *Use case:* the card no longer looks trapped inside the frame after detaching.*

### Addendum — Canvas sketch (shapes & pen)

- **Sketch tools:** Rectangle, ellipse, line, arrow, and freeform pen as **canvas objects** on the world board — vector shapes and smoothed paths for annotations and whiteboard-style markup alongside notes. *Use case:* highlight areas, draw arrows, or add quick freehand notes directly on the board.*
- **Object menu:** Access via **Object** → **Sketch** (submenu) in the toolbar — tools no longer occupy a separate icon row in the rail. *Use case:* slimmer toolbar; sketch tools grouped with icon, label, image, and map inserts.*
- **Shortcuts:** `shortcut:canvasDrawRect`, `shortcut:canvasDrawEllipse`, `shortcut:canvasDrawLine`, `shortcut:canvasDrawArrow`, and `shortcut:canvasDrawFreeform` (defaults **R**, **O**, **L**, **A**, **P**) appear in the **canvas cheat sheet** (keyboard chip **top-left** on the board) and in the global shortcut help — even though tools live only in the submenu. *Use case:* draw quickly without opening the menu.*
- **Draw mode:** Hint above the toolbar; **Esc** or choosing the same tool again exits; **pan-on-drag**, **node drag**, and **connection mode** are disabled while drawing.
- **Properties:** Stroke/fill colour, stroke width, line style; optional **smooth path** for freeform (Catmull-Rom). Resize with selection handles like other canvas objects.
- **WIP:** Until shipped, a **work-in-progress stamp** covers the sketch submenu; developers: enable **`canvasShapes`** under **Dev Workbench → WIP feature bypass**.
- **Audit & export:** `canvas_object:created`, `moved`, `deleted` in the audit log; TOON export includes `canvas_objects`.
- **Help:** New **Canvas sketch tools** help document (DE/EN), cross-linked from **World canvas**.

## Editor

- **Smart paste:** Paste a screenshot and it becomes an inline image; paste a supported file and it is imported as an attachment linked at the caret. *Use case:* drop research material into a note without leaving the keyboard.*
- **Right-click mini-toolbar:** Formatting actions appear on right-click only — context-aware (image alt text, links, mentions, or full text tools). *Use case:* less clutter while writing; more power when you need it.*
- **Dark mode readability:** Headings, bold links, and prose styling now use proper contrast in dark mode. *Use case:* long reading sessions without eye strain.*
- **Attachments sidebar:** Lists all files belonging to the note; **Add** imports only, **Toolbar → Attachment** inserts a link. *Use case:* manage files separately from body text.*
- **Read split view:** Open two notes side by side in read mode — embeds and block references open in the trailing pane. *Use case:* compare source and reference while reading.*
- **Block references & paragraph links:** Copy a paragraph reference from the toolbar or context menu; paste a single reference line to insert a link. Hover shows a snippet preview. *Use case:* link to exact passages, Obsidian-style.*
- **Embedded notes:** Embed another note inline — full note or a **section from a heading**. Circular embeds show a clear warning. Formatting is preserved; live updates when the source changes. *Use case:* build hub pages from existing content without duplication.*
- **Footnotes:** GFM footnotes with **Ctrl+Alt+F**, toolbar buttons, and a visual **Footnotes** section in the editor. Optional **page-wise footnotes** in PDF export (Word-style, at page bottom). *Use case:* academic or lore notes with proper citations.*
- **PDF notes:** New **PDF** note type — view, highlight, underline, and annotate pages; link annotations to other notes. Open PDF attachments from any note via **View in app**. *Use case:* research PDFs stay inside your knowledge graph.*
- **Reading time & complexity:** A badge shows estimated reading time and complexity (Low / Medium / High) while editing; read mode shows it under word count. *Use case:* gauge note depth before sharing or presenting.*
- **Start date:** Notes can have an optional **start date** alongside the due date — used by the Kanban timeline. *Use case:* plan work spans, not just deadlines.*
- **Aliases (alternate names):** Optional **aliases** per note in editor metadata or **Properties…** on the canvas — unique project-wide (case-insensitive). **Graph search**, **@-mentions**, and **wikilinks** on import (`[[Alias]]`) resolve all names. *Use case:* link the same character as “Aragorn” and “Strider” without renaming the title.*
- **Read mode — metadata parity:** **Start date**, **attachments** (view and download only), and saved **journal mood** (emoji) appear in the metadata column like in edit mode. *Use case:* full context while reading without switching modes.*
- **Block comments in read mode:** Margin icons open a **read-only** popover with all comments for that paragraph — writing and deleting stay in edit mode. *Use case:* follow discussions without accidental edits.*
- **Read mode — read aloud:** When the note is **not a PDF** and has body text, the **speaker** icon in the header (including **focus mode**) starts text-to-speech for **title**, optional **summary**, and **note body** — Markdown is converted to plain text for speech; the button **pulses** while playback runs. *Use case:* listen to long notes without leaving read mode.*
- **@-mention picker position:** The `@` autocomplete (note list and relation-type step) flips **above** the caret when there is not enough space below — no longer clipped at the window bottom or app chrome. While you **scroll** in the editor, the picker stays aligned with the caret. *Use case:* link to other notes comfortably from the lower part of a long note.*

### Addendum — Kanban timeline UX

- **Drag-pan:** Move horizontally by **clicking and dragging** on **empty timeline space** (ruler or lane background) — **no visible horizontal scrollbar**. Alternatively **Shift + mouse wheel**.
- **Two-tier date ruler:** Month/year on top (year only at month zoom), day numbers with weekday, calendar weeks, or month abbreviations below — weekends and **today** highlighted in columns.
- **Bar stacking:** Overlapping cards in the same swimlane (same or intersecting date range) are **automatically placed on lower rows** — the lane grows taller as needed. *Use case:* several tasks in the same sprint window without bars covering each other.

### Addendum — schedule dependencies (properties)

- **Predecessors & successors:** In **Properties…** (world canvas) under **Schedule & metadata** — multi-select via search (title and alias), kept in sync on both sides.
- **Optional canvas:** Per dependency, **Link on canvas** — then choose edge type and strength; without the toggle, schedule metadata only (no visible edge). Existing **`depends_on`** edges are imported on migration **V47**.
- **Cycle hint:** Circular chains are saved with a **warning toast**. Timeline arrows / critical path are planned for later.

### Addendum — timeline dependency lines

- **Timeline arrows:** **Show dependencies** toggle in the header — finish-to-start arrows from predecessor end to successor start, from **`node_schedule_dependencies`** (not canvas edges only).
- **Visibility:** Only when both packages have a visible bar; elbow routing between swimlanes.
- **Persistence:** Per-project `localStorage` setting; default **on**.

### Addendum — timeline external dependencies (ghost bars)

- **Ghost swimlane:** **Show external dependencies** toggle in the header (off by default, only when dependencies are on) — packages outside the active board in the **External dependencies** swimlane (normal bars, dedicated lane).
- **Arrows:** Dependency lines between board packages and external packages (at least one endpoint on the board).
- **Persistence:** Per-project `localStorage` setting; default **off**.

### Addendum — timeline displacement for dependency lines

- **Displacement:** **Displace bars for dependency lines** toggle in the header (off by default, only when dependencies are on) — obstructing packages move to extra rows within their swimlane so arrows are not hidden underneath.
- **Scope:** Horizontal corridors in the same swimlane (L–M–R scenario) and vertical/elbow segments between swimlanes.
- **Combined use:** With **Show external dependencies** — displacement also applies to edges between board packages and the external swimlane.
- **Persistence:** Per-project `localStorage` setting; default **off**.

### Addendum — timeline displacement: external dependency fix

- **Cross-lane:** Vertical arrow segments cannot be cleared by row displacement alone — **elbowX rerouting** avoids obstructing packages in intermediate swimlanes.
- **External lane:** Long horizontal target segments still displace obstructing neighbour bars in the same swimlane.
- **User impact:** Arrows between board and external lane (e.g. Game vision → AnimationSystem) cross fewer unrelated packages; predecessor/successor bars on the edge stay put.
- **No new toggle:** Existing **Displace bars for dependency lines** option; turning dependencies off resets displacement and disables the checkbox.

### Addendum — Board context menu

- **Richer card context menu:** Right-click a **Kanban card** (column board, **timeline bar**, or card in the **dashboard Kanban widget**) opens a menu on par with the canvas — **status** and **bucket** quick setters (checkmark on current assignment), **colour** (palette picker), **Properties…**, **Connections…**, **Duplicate…**, **Open in editor**, **Export PDF…**, **Move to inbox** (when the note is on the canvas), and **Delete note** (with confirmation).
- **Switch board:** **Move to board** lists other boards in the project — quick assignment without the full Kanban assignment dialog.
- **UX:** Portal menu with **viewport clamping**, icons, and sound like the world canvas; the **target card** stays **highlighted** while the menu is open.
- **Shared menu core:** Node actions reuse the canvas context menu core (`NodeContextMenuCore`) — consistent behaviour, less duplicate code.

### Addendum — column appearance (icon & accent colour)

- **Workflow status identity:** Each **workflow status** (built-in or custom) can have a **Material icon** and **accent colour** — stored **project-wide** in the project database (migration **V46**). The stable key is the status **slug** (e.g. `draft`, `active`, `planning`); this is the same field nodes use as **status** and prepares future status display on the **world canvas**.
- **Where to configure:** **Project dashboard → Templates** tab (workflow status list) **or** **Board → Configure columns** — both edit the **same** values for status-backed columns. **Bucket columns** get their own icon and colour on the column record.
- **Board UI:** Column headers show the icon and a coloured accent (top stripe and title tint). **Default-style** and **canvas-style** cards show a small **column/status badge** (icon in accent colour) once a card sits in a column — including the dashboard Kanban widget preview.
- **Built-in defaults:** Draft, Active, Review, and Archived ship with preset icon/colour pairs on first migration; custom statuses start neutral until you pick an appearance.
- **Icon picker — full registry:** The icon dialog lists **all** registered Material icons — no manual curated list. Search matches **icon id**, **Material ligature name**, and **tags**. New registry entries appear in Kanban pickers automatically.
- **Import:** Importing workflow statuses from another project copies **icon** and **accent colour**; board columns are rebuilt and inherit status appearance automatically.
- **Timeline:** Swimlane labels in timeline view show the column icon when set.

## AI Assistant

- **Focus-mode orb:** In immersive focus mode, the assistant appears as a bottom-left orb — hover for microphone and composer, expand for full chat. *Use case:* stay in flow without a wide sidebar.*
- **Chats per project:** Switching projects shows only that project's threads; chat titles appear after the first reply. *Use case:* separate contexts per world or client.*
- **Connection mode banner:** Sidebar shows **Local** vs **Online** with a link to settings. Read-only warning when write permissions are off. *Use case:* always know what the assistant can do.*
- **ElevenLabs voices:** Three curated voices plus custom voice ID; preview in app settings; API key per project on the dashboard. Word highlighting during speech with system voice. *Use case:* JARVIS-style read-aloud while reviewing lore.*
- **Canvas refresh after tools:** Changes from AI tool calls appear on the canvas immediately — no manual reload. *Use case:* let the assistant create notes and see them right away.*
- **AI activity dashboard:** Metrics tab shows how many objects AI created, edited, deleted, and retrieved — with weekly overview. *Use case:* understand how much the assistant contributes to a project.*
- **Voice input (focus orb):** **Microphone** or **orb click** starts **dictation** via the **Web Speech API** — live transcript in a speech bubble, **15 second** time limit, pulsing mic ring while recording. Recognized text lands in the **composer** by default; click again to stop. *Use case:* dictate prompts without leaving the canvas.*
- **Auto-send dictation:** Under **App settings → AI assistant**, optionally enable **Auto-send dictation** — when voice input ends, the message is **sent to the model immediately** without stopping in the text field. Persisted as **`AutoSendDictation`** in **Nodio.ini** **`[AiAssistant]`** (default **off**). *Use case:* hands-free chat in focus mode.*

### Addendum — Whisper speech recognition (updated: CLI sidecar)

- **Offline dictation (Whisper.cpp):** Replaces Web Speech / Windows SAPI — microphone → AudioWorklet (16 kHz mono) → **`whisper-cli.exe`** (sidecar process, whisper.cpp v1.8.4); live transcript every **2 seconds** in the focus orb speech bubble; **60 second** time limit.
- **Architecture — CLI sidecar:** `whisper-cli.exe` is spawned per audio chunk via `spawn` (temp WAV → `-oj` JSON output). Crashes stay inside the sidecar and cannot kill the Nodio main process — industry-standard pattern (OpenWhispr, Buzz, ChordVox).
- **Default `small` model:** Multilingual **ggml-small.bin** (~466 MB) bundled in the installer under `resources/whisper/` — ready on first use. **`WhisperModelId=small`** in **Nodio.ini** **`[AiAssistant]`**.
- **Settings → Speech recognition:** Model list (`tiny` … `large-v3-turbo`) with size, status (installed/active), download with progress, activate button. **New — "Re-download":** a refresh button on each installed model forces a fresh download — useful when the model file is in an outdated ggml format that causes a startup crash.
- **Robustness:** Toasts for missing model/CLI errors; clean mic/worklet cleanup.
- **Implementation:** Decision doc `Documentation/Development/WhisperBindingDecision.md` (section *Final decision LB-0014: CLI sidecar*).
- **Installer:** Size increases by ~470 MB (bundled small model) + ~4 MB (`whisper-cli.exe` + DLLs under `resources/whisper/bin/win-x64/`).

### Addendum — Focus composer (auto-resize)

- **Composer grows with content:** The textarea in the **focus orb slim composer** (and the sidebar chat composer) auto-resizes to fit typed text — up to about **256 px**, then scrolls inside the field. During **dictation**, the field grows with the live transcript. *Use case:* longer prompts and dictation without a clipped input area.*
- **Demo button removed:** The legacy **Demo** control in the slim panel header (mock reply with TTS preview) is gone — replies and read-aloud use the production model and ElevenLabs.

## Addendum — Bug Reporter Assistant (Beta)

Beta tester assistant (**beetle icon** in the title bar, beta channel or `betamode.nbn`): centered modal with a **3-step wizard** (Describe → Analyze → Submit), AI chat, dictation, screenshot vision, ZIP, and Discord handoff.

### Wizard & UX

- **Modal redesign:** Larger centered window (`BugReporterModalShell`), **stepper** for the three steps, **draft** in `localStorage` (resume dialog, 7 days).
- **Header “New”:** Discard draft and start over — with **confirmation** when chat, text, handoff fields, or screenshots already exist; disabled while streaming.
- **Analyze → Submit:** Forward CTA labeled **Submit** (matches step 3 in the stepper), no longer “Continue → Discord”; visible as a secondary button, enabled after the first **AI reply**.
- **AI analysis as Markdown:** Replies render with lists, paragraphs, and **bold** (`BugReporterMarkdown`); internal draft block (`---bug-report-draft---`) is hidden in the UI (including while streaming).

### Assistant & handoff

- **Formulate reports, not fix issues:** System prompt focuses on title, repro, and expected vs. actual — **no** troubleshooting, workarounds, or settings advice (broker, MCP, beta flags); help context only to classify expected behavior.
- **Handoff prefilling:** AI draft (JSON at end of reply) fills title, description, and repro steps; on **Submit**, additional fallback via `parseHandoffDraft` without visible draft marker.
- **Discord step unchanged:** Copy text, open channel, attach ZIP manually.

### Guided submit handoff (addendum)

- **Sub-stepper on the Submit step** (`BugReporterHandoffStepper`): three numbered steps with connector lines (aligned with the main wizard stepper), shows the active step — no click-to-skip.
- **Strict sequence:** ① **Create ZIP** (title required) → Explorer reveals the folder with the ZIP selected (`shellRevealPath` / `revealExportOutput`) → ② **Copy text** (after ZIP) → ③ **Open Discord channel** (after a successful copy). One primary action per step; optional **Create ZIP again** (resets the copy step).
- **Discord desktop app:** Configured channel URL (`https://discord.com/channels/…` in `distributionConfig.bugReporter.discordChannelUrl`) is converted to `discord://-/channels/…` on open — prefers the installed Discord app over the browser only (`discordDeepLink.ts`, `shellOpenExternal`).
- **Stability & handoff content:** Fix for `bugReporter:getConfig` (missing `resolveBugReporterConfig` import in the main process). Empty Submit pane when no session was active: `ensureSession` on navigation, “Preparing session…” placeholder, draft resume with a new session when `sessionId` expired.

### Configuration (testers)

- **`Nodio.ini` `[BugReporter]`:** `ProxyBaseUrl`, `BearerToken` (encrypted), `Model` — shipped defaults on first start; **no** app settings panel for testers.
- **`distributionConfig.bugReporter`:** `proxyBaseUrl`, `defaultModel`, **`discordChannelUrl`** (channel deep link for handoff step 3; empty = “channel URL not configured” hint).
- **Backend proxy:** `Srv/BackEnd_BugReporter`; beta ship via `phase-ship-beta.ps1`.
