# Nodio 0.6.6

**Release date:** July 2026

This release fixes several friction points during first launch and guided onboarding reported from beta testing — including a tour that could hang while scrolling, a blocked window, and a lost color scheme choice.

---

## Bug fixes

- **Guided project creation no longer gets stuck:** When you scroll the form during the onboarding tour, the spotlight now follows the target area reliably instead of dimming the entire screen with no clear way out.
- **Back button in the tour:** The onboarding tour now has a **Back** button alongside **Next** and **Skip**, so you can revisit earlier steps.
- **Project is created reliably:** The tour no longer appears to advance pointlessly when no project exists yet. After you actually create the project, you land directly on the canvas without additional tutorials being chained automatically.
- **Window controls stay reachable:** Minimize, maximize, close, and the title bar drag area work while onboarding overlays or the first-run hub are open.
- **Color scheme choice is preserved:** A color chosen in the setup wizard (e.g. **Forest**) is now applied reliably instead of reverting to the default when you finish.
- **Offline read-aloud (Piper) works reliably:** When **Piper** was selected as the voice, read-aloud could silently fall back to the **system voice** instead of playing the offline voice — fixed.
- **Piper preview without noise:** Voice preview in the Piper catalog now sounds natural again — previously WAV audio was corrupted on Windows due to text-mode stdout (crackling/static).
- **Activating a Piper voice switches read-aloud:** **Activate** in the Piper catalog now also sets the **read-aloud voice** to Piper — node read-aloud no longer silently uses the Windows system voice.
- **Rapid voice switching no longer interrupts previews:** Listening to several voices in quick succession in the Piper catalog no longer aborts the still-running synthesis of the previous voice.
- **Sub-canvas badge shows layers icon:** On canvas containers with sub-notes, the badge now shows the correct layers icon instead of a question mark.
- **Tutorial steps — text wrapping:** Long instruction text in the tutorial card (e.g. collapse/expand groups) was cut off on the right instead of wrapping; text now wraps reliably.
- **Saved views remember canvas level:** Creating a view stores the current sub-canvas level; opening a view navigates to that level before applying camera and group collapse. Views PNG export in Export Center filters each view to its level only.
- **Sub-canvas: no more orphaned content on delete/type change:** Deleting a note with its own sub-canvas, or changing its note type away from "Canvas", now actively asks whether the nested notes, groups, and objects should be moved up one level or deleted along with it — previously such content could become unreachable or the delete could fail outright.
- **Search in list mode now jumps to the correct sub-canvas level:** A hit that lived on a different level than the one currently open used to stay invisible in list mode because Nodio never switched levels automatically.
- **Saved view with a deleted sub-canvas no longer hangs:** Now shows a hint and opens the root level instead of getting stuck with no feedback.
- **Sub-canvas drag & drop for notes:** Dragging notes onto a container or the portal failed with “Unknown node patch field parentNodeId” — fixed. Groups and canvas objects were not affected.
- **Canvas notes at deepest sub-canvas level:** On the third (deepest) canvas level you can no longer create new canvas notes or convert a note to the canvas type — there would be no room for a child level underneath. Regular notes, groups, and canvas objects remain allowed; existing canvas notes on that level are left unchanged.
- **Export Center: switching canvas scope cleans up the note selection:** Changing the export level in the PDF tab now automatically drops selections that no longer belong to that level; a previously chosen canvas level that has since been deleted now falls back to the root level with a hint.
- **Time-lapse layer-by-layer mode without empty intermediate steps:** Changes outside the chosen canvas level that couldn't be attributed to any sub-level used to pad out the timeline unnecessarily.
- **Reading-time badge no longer overlays text:** In edit mode, the read time and complexity badge sat in a sticky footer over the text field and hid the last lines while writing — it now appears at the top next to the content label; in read mode it also shows in the pill row under the title.
- **@-mentions keep their connections:** After saving a note with `@` links, edges on the canvas and in the references panel disappeared — the sync did not recognize HTML-serialized `nbn:` links (block IDs) and deleted mention connections on the next autosave.
- **Markdown export: mentions and edges:** Live-Write and export now convert editor HTML mentions to Obsidian wikilinks as well; typed connections (`?rel=…`) export without broken UUIDs. Vault import restores `_meta/connections.ndjson` (all connection types, not only references from wikilinks).
- **Portal edges dock left/right:** Connections to the portal node now pick the appropriate side anchor like regular notes — edges from nodes to the right of the portal no longer stretch awkwardly across the canvas.
- **Cross-level connections across multiple levels:** A link between root and deepest level now appears on every intermediate level as a dashed shadow edge (portal → container or container ↔ container), not only up to the immediate parent level.
- **Portal double-click:** **Double-click** on the portal node always moves up one sub-canvas level — even when connections to other levels exist (single-click still jumps to the counterpart). Double-clicking the portal no longer creates a new note (clicks previously fell through the non-interactive portal wrapper onto the canvas).
- **Visual style decorations no longer clipped:** For **Corkboard** (red push pin) and **Zettelkasten** (tape strip at the top), the pin and stripes were cut off at the edge on the canvas and in the properties preview — fixed.
- **Project settings stay stable after deleting an asset:** Removing a graphic under **Settings → Project → Files** no longer shifts the page upward with a large empty gap — the toast was only coincidental; the files list is no longer fully hidden during refresh.
- **Focus mode: journal in the main bar:** **Journal** appeared in the primary navigation while focus mode was on, but clicking it ended focus mode — **Journal** is no longer shown there; reach it via the **…** menu (intentionally leaving focus mode).
- **Focus mode: sub-canvas path visible:** On a sub-canvas level, the floating **graph search** covered the **path breadcrumb** — in focus mode the path now appears **top-left** while search stays centered. The trail starts **to the right of** the keyboard-shortcuts chip; **long titles** truncate with **…** before reaching the search bar (full name in tooltip).
- **Focus mode: action buttons no longer overlap:** When the metadata sidebar is docked, star, edit, and the other actions no longer stack on top of each other — the bar wraps to a second row when needed.
- **Focus mode: metadata below the action bar:** Scrolling the sidebar no longer slides content (e.g. tags) under the floating action bar.
- **Focus mode: title and shortcuts:** The large note title in read mode no longer covers the keyboard-shortcuts button at the top left.
- **Focus mode: sidebar toolbar:** Pin, edit, and the other actions share one header row in the metadata sidebar — no more overlap, a continuous divider below, and pin tooltips open downward.
- **Focus mode: title bar:** The top bar is no longer nearly transparent, so the sidebar no longer appears to bleed through the title bar at the top right.
- **Focus mode: shortcuts no longer overlap content label:** In edit focus mode the floating keyboard-shortcuts chip at the top left covered the "Content (Markdown)" label — the content area now uses the same top spacing as read focus mode.
- **Focus mode: no empty band below the title bar:** In focus mode, content and the metadata sidebar now sit flush under the title bar — the previously visible dark gap is gone.
- **Views: camera stays put during thumbnail generation:** If you create a new view and pan away immediately, the camera no longer jumps back when the preview image finishes generating.

## New

- **Offline read-aloud (Piper):** The AI assistant and node read mode can now read text aloud offline with **Piper TTS** — noticeably more natural than the Windows system voice. **German** and **English** (high quality) are available immediately; **120+ additional voices** in many languages can be downloaded under **Settings → Language & sound**.
- **Linux & cross-platform:** This release also prepares a **Linux release** (AppImage). It includes **Whisper dictation binaries for Linux** (official v1.9.1) and **Piper** for Windows, macOS, and Linux.
- **Sub-canvas navigation enabled:** Nested canvas levels are now available in the app by default — double-click, breadcrumb, portal, shadow edges, and drag & drop between levels without a dev bypass or WIP gate.
- **AI & MCP — sub-canvas tree:** New tool **`get_canvas_tree`** (MCP: `nodio_get_canvas_tree`) returns the nested sub-canvas hierarchy of a project in one call — title, type, and child count per note, without full body text. Useful for assistants mapping or reorganizing nested canvas structures.
- **Time-lapse per canvas level:** In the time-lapse player you can choose **root canvas** or a **sub-canvas note** — replay shows only changes on that level. Container cards show a badge when changes occurred in a nested sub-level. The scope dropdown uses **breadcrumb-style** labels with the project name as root (e.g. `My Project > Chapter A > Ideas`).
- **Export Center — pick canvas:** In the **World canvas** and **PDF** tabs you pick the export level from a dropdown (only when sub-canvases exist). Each row shows the **full breadcrumb path** with the project name as root — e.g. `My Project`, `My Project > Chapter A`, `My Project > Chapter A > Ideas` — so you can tell which canvas you are exporting even when note titles repeat or levels are nested. PNG export shows only direct children of the chosen level. PDF export filters the node list to that level; optionally you can append **sub-canvas contents** of the exported note as a separate section.

- **Sub-canvas surfaces:**
  - **Editor breadcrumb with full path:** The breadcrumb now shows `Project > Canvas > A > B > Title`; clicking an intermediate level jumps there. When deeply nested, an overflow menu collapses the middle levels.
  - **Dashboard "Sub-canvases" card:** Shows the number of sub-canvases and the largest sub-canvas (with recursive note count) — only appears when sub-canvases exist.
  - **Kanban board "Allow notes from all levels":** New board toggle — on, the board aggregates notes from every sub-canvas level (with a canvas-location chip and "Show on canvas"); off, it shows only the current level as before.
  - **Mention picker with path & create:** Target notes from sub-canvases show their container path; an empty query lists recently edited notes; "Create new note" makes the note on the source note's level including the connection.
  - **Cross-level connections made visible:** Connections to other levels appear as dashed **shadow edges** to the container (click opens the sub-canvas) or at a **portal node** (click jumps to the counterpart).
  - **Drag & drop into sub-canvas:** In normal mode you can drag notes, groups, and canvas objects (including multi-select) onto a container — it highlights while hovering; on release the items move into that sub-canvas. Dropping on the **portal** instead also highlights it; on release the items move one level up (like clicking the empty portal).

- **Three new starter templates:** When creating a project you can also pick **Certification Roadmap** (cert prerequisite graph + exam-prep Kanban), **Content Pipeline** (editorial Kanban + topic clusters), and **AI Workflow** (prompt variant tree + experiment runs, MCP-first) — each with demo nodes, a board, and a saved view.
- **Color canvas icons and text labels:** In the properties dialog for icon and text objects you can pick a color or reset to the theme. Existing objects without a custom color look unchanged; web viewer export and AI/MCP use the same setting.
- **Kanban WIP limits in the project:** The max card count per column is now stored in the **project file** (not only on this device) — limits travel with exports and templates. You can set and query limits via **AI/MCP**; on first board open, older device-local limits are migrated once.
- **Template tours (WIP):** Template authors can add a short guided tour in the Template Builder (anchors on canvas, board, journal, UI elements, and more). Opening a project from such a template offers to start or dismiss the tour — dismiss is remembered on the device. Gated behind a feature flag in normal builds; testable via Dev Workbench.
- **Five new AI providers:** Under **App settings → AI assistant** you can now also use **OpenRouter** (one API key, many models including GPT, Claude, and Gemini), **Mistral AI**, **DeepSeek**, **Groq (LPU)**, and **LM Studio**. **LM Studio** joins **Ollama** in **Local** connection mode; the other four are cloud providers in **Online** mode.
- **Views — sort per folder:** To the left of the folder **⋯** menu you get a **sort icon** (↕). Default is **Name** (natural: `01`, `02`, `10`); switch to **Recently created** or **Manual** (drag & drop and move up/down only in that mode). The choice is stored device-locally per folder.

## Improvements

- **Portal node fixed at origin (sub-canvas):** On every sub-canvas level the portal node now **always** appears at **(0, 0)** — even without connections to other levels. **Click with no connections** moves up one level. Overlapping notes, groups, and canvas objects are **repelled** automatically (same heuristic as open group frames).
- **Portal appearance selectable:** Under **Settings → Project → Appearance** (World Canvas) you can choose how the portal node looks **per project** — **classic**, **vortex** (neon ring + swirl + sparks, default), **glow core**, **subtle**, **fantasy** (organic ring + rising sparks), **steampunk** (brass gear + energy core), or **hover boost** (calm, full vortex on hover). All glow styles now feature a wide soft **halo**, a bright **neon ring**, and a dark portal center. A **live preview** next to the selection shows style and color instantly. With no connections the portal glows more softly; with system reduced motion you get a static glow instead of animation.
- **Portal color per project:** By default the portal follows the **design's primary color** (fantasy and steampunk glow green). A **color picker** under **Settings → Project → Appearance** lets you set a custom color — glow, ring, swirl, and sparks follow your pick.
- **Portal size per project:** Under **Settings → Project → Appearance** you can choose the portal **size** (small through extra large) — independent of style. The live preview scales with your pick. Repel and drag-and-drop targets follow the selected size.
- **Fantasy portal as oval:** The **fantasy** style renders as a **tall oval** (like classic forest portals); all other styles stay circular.
- **Portal glow without stray ring:** An occasional **primary-color border** around the portal (pulse animation) was removed — glow now comes solely from the visual engine's halo and neon layers.
- **Edges: unified tooltips and click actions:** **Hover** on normal and shadow/portal edges shows the same connection info as between notes. **Click** opens a dialog with **Edit connection** and **Jump to destination** (on normal edges, jump focuses the target on the canvas; on shadow edges it opens the sub-canvas or jumps to the counterpart).

- **Consistent settings width:** All sections under **Settings** now use the full available width — like **Keyboard shortcuts** already did — instead of a narrower column. Design, project, navigation, and the other tabs feel more consistent.
- **Read aloud under Language & sound:** Voice selection for read-aloud and the **Piper voice catalog** now live under **Settings → Language & sound** instead of AI assistant — a better fit for language and audio.
- **Piper voice catalog:** Search, filters (installed, active, recommended, bundled), descriptive voice cards, and per-voice preview.
- **Piper as default read-aloud voice:** The Windows system voice is no longer selectable — **Piper** (DE/EN preinstalled) is always the default for read-aloud and AI focus mode.
- **Read aloud starts faster:** Long notes are prepared and played sentence by sentence — the first audio arrives much sooner instead of waiting for the full synthesis. The read-aloud button shows a progress spinner while preparing.
- **Canvas notes open the sub-canvas directly:** Clicking a note of type **Canvas** navigates into its sub-canvas instead of the read view. You can still edit the note itself via the context menu with **Open in editor**.
- **Sub-canvas badge is clickable:** Clicking the layers badge (with sub-note count) opens the sub-canvas directly.
- **Search shows canvas path and jumps to the right level:** Hits in a sub-canvas show the path under the title (e.g. "in: Project plan / Q3 ideas"). When jumping to the canvas, Nodio automatically switches to the correct sub-canvas level before focusing the card — in the title bar search; the command palette also shows the path.
- **Bug Reporter hidden:** The beetle icon in the title bar and the AI-assisted bug reporter are temporarily disabled. The automatic crash assistant (Bug Wizard) remains unchanged.
- **Project overview — size slider:** Next to the **Cards/List** switch is a **7-step size slider** from a **very compact list** through a **row-to-grid** crossover to **fewer columns** and slightly **larger cards**. The switch jumps to the extremes; the slider sets steps in between — including **archived projects**. Stored per device in `localStorage`.
- **Windows installer — more professional setup:** The NSIS installer now remembers desktop shortcut and sign-in autostart choices across updates, shows a branded header banner on inner pages, renders sharper on high-DPI displays, and lists help/update links to nodio.dev in Windows Apps & features.
- **Live preview for image fit and styles:** In canvas image object properties you see fit, visual style, and rotation immediately in a preview — including mini tiles on the style chips. Under **Settings → Project → Appearance**, a small tile next to image fit shows how cover/contain and opacity affect the backdrop right away.
- **Canvas object properties wider and more compact:** The image object properties dialog now uses width better — preview on the left, **image fit** and **rotation** on the right; **visual style** tiles wrap in a grid instead of scrolling horizontally. Polaroid mini previews match the canvas result more closely.
- **Text labels: style in edit dialog:** **Edit label** (double-click or context menu) now includes **alignment**, **font size**, and **text color** — together with the label text in one dialog. Text label properties are limited to **size**, **border**, and **opacity**.
- **Template tour in the title bar:** Projects with one or more guided tours show a route icon in the global icon bar (next to MCP and AI assistant). Click opens the tour offer dialog — with multiple tours you pick first. The button only appears when a tour has at least one step.
- **AI assistant — provider list and model picker:** Provider selection uses a unified grid with logos. **xAI Grok** and **Groq (LPU)** are clearly distinct labels. For **OpenRouter**, **Groq**, and **LM Studio**, the model dropdown loads available models live from the provider (on failure: free-text input). **Mistral** and **DeepSeek** show a short hosting notice (EU vs. outside the EU).
- **Focus mode navigation clearer:** The main bar in focus mode shows only **focus surfaces** (canvas, editor, views, board). The **…** menu lists **projects**, **dashboard**, **journal**, **audit**, and **export** — with a note that these destinations end focus mode; **Exit focus mode** is at the top (also on editor/views where the canvas subnav row is missing).
- **Focus mode: action bar follows common patterns:** In editor and read focus mode, floating actions are grouped logically — **Edit** or **Read** first, then favorite and history, read-aloud and focus music as reading aids, **Exit focus mode** before the destructive **Delete** action on the far right.
- **Settings — compact onboarding buttons:** **Start setup wizard**, **Reset onboarding**, and **Restart tutorial** in the left settings sidebar are now colored icon cards in a row — the same style as the tutorial picker at the end of the basic tutorial. Labels appear on hover as tooltips; screen readers still reach the actions via `aria-label`.
- **List view — consistent layout switcher:** The **table**, **gallery**, and **cards** switcher now uses the same segmented slider as the canvas sub-navigation and settings — including the same sliding-pill animation.
