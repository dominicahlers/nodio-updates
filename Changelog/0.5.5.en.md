# Nodio 0.5.5

**Release date:** April 2026

Version **0.5.5** is a large incremental update: richer canvas and board workflows, a full journal hub, Live-Write export, smarter search, and many quality-of-life fixes on the path to a stable release.

---

## Canvas

- **Viewport backdrop:** In **Project dashboard → Appearance**, set a custom background image or underlay colour for light and dark mode — with fit mode and opacity. The grid stays on top. *Use case:* give each project a distinct visual identity or subtle watermark look.*
- **Undo & redo:** Move nodes, groups, objects, or create connections — then undo with **Ctrl+Z** and redo with **Ctrl+Shift+Z** or **Ctrl+Y**. Toolbar buttons show when history is available. *Use case:* experiment freely on the board without fear of breaking layout.*
- **Multi-select mode:** Press **V** to toggle selection mode, drag a rubber-band box, then group, move, or delete everything at once. Selected group frames become subgroups correctly. *Use case:* reorganise a cluster of notes into a new group in one step.*
- **Multi-select — bulk actions:** When **notes** are selected, the floating toolbar adds **status**, **card colour**, **tags** (add or remove), **archive** (with confirmation), and **PDF (batch)** (up to 50 notes). Changes are saved via batch update (max. **300** notes per operation) — no need to switch to list view. The bar shows **total selection count** and **note card count** separately; **canvas objects** (symbols, images) are excluded from bulk actions. With **group frames** in the selection, a dialog asks whether to include on-canvas notes **inside** those groups (including subgroups and collapsed groups); **archive** still uses a second confirmation afterward. *Use case:* recolour, tag, or export several cards on the board in one step.*
- **Connection storytelling:** Hover a connection line to see from → to, relation type, creation date, and optional label or description. *Use case:* understand at a glance why two notes are linked during a review.*
- **Connection strength:** Set strength **1–5** when editing a connection — stronger links draw thicker and more opaque. *Use case:* distinguish weak references from core relationships in a dense graph.*
- **Graph search:** Results are ranked by relevance, not just recency — the best title or content match rises to the top. *Use case:* find the right note quickly in projects with hundreds of entries.*
- **List view — saved views:** At the top of **list view**, pick **Standard view** or a **saved profile** (**Save**, **Save as new**, **Delete**). **Layout:** **Table** (virtualized, as before), **Gallery** (card grid with type/status and excerpt), or **Cards** (wide rows with metadata). **Columns** in table mode can be shown/hidden and reordered with arrows; **click a column header** toggles sort direction. **Filters:** multi-select **status** and **type**, **Starred only**; sort by title, type, status, created/updated, or **word count** — replaces the fixed “last modified” order. **Graph search** in the title bar still intersects the list. Profiles live in the project DB (`list_view_configs`); edits to the active view are **debounced** to disk. *Use case:* e.g. a “review” gallery filtered by status or a compact table for bulk edits — without reconfiguring every session.*
- **Spotlight fix:** Picking a search hit no longer causes repeated camera jumps or flickering highlights. *Use case:* jump to a note once and stay focused.*
- **Minimap markers:** Starred notes show as amber dots; notes edited in the last 48 hours as green dots. *Use case:* spot favourites and recent work while navigating a large canvas.*
- **Import via inbox:** Markdown import moved into the **inbox drawer** — drop files there or onto the canvas (the drawer opens automatically). Imported notes land in the inbox first. *Use case:* bulk-import a vault, then drag only what you need onto the board.*
- **Insert image from gallery:** When adding an image, choose **Upload new** or **From project gallery** instead of always opening the file picker. *Use case:* reuse assets already in the project.*
- **Collapsed group labels:** Group names appear again as pills beside collapsed circles. *Use case:* identify groups without expanding them.*
- **Connections inside groups:** Lines to cards inside a group are no longer hidden behind the group fill. *Use case:* follow relationships within nested structures.*
- **Canvas time-lapse:** Replay how your project grew from the audit log — play, scrub, auto-follow the camera, and export **WebM** video. Range and speed are configurable. *Use case:* show stakeholders how an idea evolved over weeks.*
- **View slideshow:** Auto-play all saved views in a folder — ideal for demos and walkthroughs. Pause, skip, adjust tempo, or loop from the on-screen HUD. *Use case:* present a project narrative without manual camera moves.*

## Editor

- **Smart paste:** Paste a screenshot and it becomes an inline image; paste a supported file and it is imported as an attachment linked at the caret. *Use case:* drop research material into a note without leaving the keyboard.*
- **Right-click mini-toolbar:** Formatting actions appear on right-click only — context-aware (image alt text, links, mentions, or full text tools). *Use case:* less clutter while writing; more power when you need it.*
- **Dark mode readability:** Headings, bold links, and prose styling now use proper contrast in dark mode. *Use case:* long reading sessions without eye strain.*
- **Attachments sidebar:** Lists all files belonging to the note; **Add** imports only, **Toolbar → Attachment** inserts a link. *Use case:* manage files separately from body text.*
- **Read split view:** Open two notes side by side in read mode — embeds and block references open in the trailing pane. *Use case:* compare source and reference while reading.*
- **Block references & paragraph links:** Copy a paragraph reference from the toolbar or context menu; paste a single reference line to insert a link. Hover shows a snippet preview. *Use case:* link to exact passages, Obsidian-style.*
- **Embedded notes:** Embed another note inline — full note or a **section from a heading**. Circular embeds show a clear warning. Formatting is preserved; live updates when the source changes. *Use case:* build hub pages from existing content without duplication.*
- **Footnotes:** GFM footnotes with **Ctrl+Alt+F**, toolbar buttons, and a visual **Footnotes** section in the editor. Optional **page-wise footnotes** in PDF export (Word-style, at page bottom). *Use case:* academic or lore notes with proper citations.*
- **PDF notes:** New **PDF** note type — view, highlight, underline, and annotate pages; link annotations to other notes. Open PDF attachments from any note via **View in app**. *Use case:* research PDFs stay inside your knowledge graph.*
- **Reading time & complexity:** A badge shows estimated reading time and complexity (Low / Medium / High) while editing; read mode shows it under word count. *Use case:* gauge note depth before sharing or presenting.*
- **Start date:** Notes can have an optional **start date** alongside the due date — used by the Kanban timeline. *Use case:* plan work spans, not just deadlines.*
- **Aliases (alternate names):** Optional **aliases** per note in editor metadata or **Properties…** on the canvas — unique project-wide (case-insensitive). **Graph search**, **@-mentions**, and **wikilinks** on import (`[[Alias]]`) resolve all names. *Use case:* link the same character as “Aragorn” and “Strider” without renaming the title.*
- **Read mode — metadata parity:** **Start date**, **attachments** (view and download only), and saved **journal mood** (emoji) appear in the metadata column like in edit mode. *Use case:* full context while reading without switching modes.*
- **Block comments in read mode:** Margin icons open a **read-only** popover with all comments for that paragraph — writing and deleting stay in edit mode. *Use case:* follow discussions without accidental edits.*
- **Read mode — read aloud:** When the note is **not a PDF** and has body text, the **speaker** icon in the header (including **focus mode**) starts text-to-speech for **title**, optional **summary**, and **note body** — Markdown is converted to plain text for speech; the button **pulses** while playback runs. *Use case:* listen to long notes without leaving read mode.*

## Journal

- **Periodic notes:** One journal entry per day, week, month, **or quarter** — find or create automatically with configurable templates per project. *Use case:* daily logs, weekly reviews, monthly or quarterly retrospectives in one flow.*
- **Journal hub:** Three-column layout with writing streak, quick actions, calendar or lists, and a year activity heatmap. Click a day to open that entry. *Use case:* see writing habits and jump to any past day.*
- **Quarterly notes:** **Quarterly** tab — titles **`YYYY-Q1`…`Q4`**, tags **`journal` + quarterly**; optional template on the project dashboard. *Use case:* quarterly reviews alongside weekly and monthly notes.*
- **Mood tracker:** Five-step mood picker on **daily notes** (edit mode); heatmap cells tinted by mood; **7-day average** in the hub sidebar; shown in **read mode** when set. *Use case:* track mood alongside writing activity.*
- **Word sprint:** Timed word-count goal on **daily notes** — presets start a countdown and progress bar in the editor. *Use case:* focused free writing.*
- **Journal search:** Full-text search across all journal periods in the hub, optionally filtered by mood. *Use case:* find past entries by topic or mood.*
- **Starter templates:** Load **Standup**, **Retro**, **Decision log**, or **Meeting notes** into your daily journal template from the project dashboard. *Use case:* start a structured entry in one click.*
- **Navigation toggle:** Enable or hide the journal link globally or per project from app settings and the project dashboard. *Use case:* journal only where you need it.*

## Kanban & Board

- **Richer cards:** Cover image, type badge, tag pills, group pill, due date, comment count, star, and checklist progress bar on each card. *Use case:* scan board state without opening every note.*
- **Quick-view drawer:** Click a card for a compact preview — resize from the left edge; open in editor or full view from there. *Use case:* triage tasks without leaving the board.*
- **Interactive subtasks:** Toggle checkboxes in the quick-view drawer; progress updates on the card immediately. *Use case:* check off items during a standup.*
- **Tag colours:** Assign colours to project tags in **Project dashboard → Appearance**; pills on cards use those colours. *Use case:* visual tag scanning across columns.*
- **Canvas card style:** Switch between compact Kanban cards and **canvas-style** cards that match your design preset. *Use case:* board that feels like a mini canvas.*
- **Card aging:** Optional amber dot on cards not updated in 7+ days; hide per column (e.g. Archived). *Use case:* spot stale work at a glance.*
- **WIP limits:** Set a max cards per column — pill turns red when exceeded (visual only). *Use case:* keep flow discipline without hard blocks.*
- **Tag filter:** Click a tag pill to highlight matching cards and dim others, or jump to list/canvas filtered by that tag. *Use case:* focus on one theme across the board.*
- **Timeline view:** Switch to **Timeline** for horizontal bars by start and due date — day/week/month zoom, today line, undated lane. *Use case:* see deadlines and overlaps across statuses.*

## Export & Live-Write

- **Live-Write export:** Mirror notes continuously as Markdown into a folder of your choice — groups become subfolders, links export as wikilinks, conflicts detected on activation. **Pull** imports external changes back. *Use case:* keep an Obsidian-compatible folder in sync with Nodio.*
- **Readable filenames:** Exported files use **`{Title} ({slug}).md`** — unique slug in parentheses; renames move the file on next sync. *Use case:* human-readable folders that still reconcile by ID.*
- **Export history:** Sidebar on the export center lists recent exports with **Re-export** to restore settings. *Use case:* repeat last PDF batch without reconfiguring.*
- **Static web viewer:** Connections, design presets, canvas objects, attachments, and note modals with breadcrumbs render correctly in the ZIP export. *Use case:* share a read-only snapshot with non-Nodio users.*
- **PDF improvements:** Native PDF pipeline (no extra browser download); optional page-wise footnotes. *Use case:* cleaner exports and smaller install footprint.*

## AI Assistant

- **Focus-mode orb:** In immersive focus mode, the assistant appears as a bottom-left orb — hover for microphone and composer, expand for full chat. *Use case:* stay in flow without a wide sidebar.*
- **Chats per project:** Switching projects shows only that project's threads; chat titles appear after the first reply. *Use case:* separate contexts per world or client.*
- **Connection mode banner:** Sidebar shows **Local** vs **Online** with a link to settings. Read-only warning when write permissions are off. *Use case:* always know what the assistant can do.*
- **ElevenLabs voices:** Three curated voices plus custom voice ID; preview in app settings; API key per project on the dashboard. Word highlighting during speech with system voice. *Use case:* JARVIS-style read-aloud while reviewing lore.*
- **Canvas refresh after tools:** Changes from AI tool calls appear on the canvas immediately — no manual reload. *Use case:* let the assistant create notes and see them right away.*
- **AI activity dashboard:** Metrics tab shows how many objects AI created, edited, deleted, and retrieved — with weekly overview. *Use case:* understand how much the assistant contributes to a project.*
- **Voice input (focus orb):** **Microphone** or **orb click** starts **dictation** via the **Web Speech API** — live transcript in a speech bubble, **15 second** time limit, pulsing mic ring while recording. Recognized text lands in the **composer** by default; click again to stop. *Use case:* dictate prompts without leaving the canvas.*
- **Auto-send dictation:** Under **App settings → AI assistant**, optionally enable **Auto-send dictation** — when voice input ends, the message is **sent to the model immediately** without stopping in the text field. Persisted as **`AutoSendDictation`** in **Nodio.ini** **`[AiAssistant]`** (default **off**). *Use case:* hands-free chat in focus mode.*

### Addendum — Whisper speech recognition (updated: CLI sidecar)

- **Offline dictation (Whisper.cpp):** Replaces Web Speech / Windows SAPI — microphone → AudioWorklet (16 kHz mono) → **`whisper-cli.exe`** (sidecar process, whisper.cpp v1.8.4); live transcript every **2 seconds** in the focus orb speech bubble; **60 second** time limit.
- **Architecture — CLI sidecar:** `whisper-cli.exe` is spawned per audio chunk via `spawn` (temp WAV → `-oj` JSON output). Crashes stay inside the sidecar and cannot kill the Nodio main process — industry-standard pattern (OpenWhispr, Buzz, ChordVox).
- **Default `small` model:** Multilingual **ggml-small.bin** (~466 MB) bundled in the installer under `resources/whisper/` — ready on first use. **`WhisperModelId=small`** in **Nodio.ini** **`[AiAssistant]`**.
- **Settings → Speech recognition:** Model list (`tiny` … `large-v3-turbo`) with size, status (installed/active), download with progress, activate button. **New — "Re-download":** a refresh button on each installed model forces a fresh download — useful when the model file is in an outdated ggml format that causes a startup crash.
- **Robustness:** Toasts for missing model/CLI errors; clean mic/worklet cleanup.
- **Implementation:** Decision doc `Documentation/Development/WhisperBindingDecision.md` (section *Final decision LB-0014: CLI sidecar*).
- **Installer:** Size increases by ~470 MB (bundled small model) + ~4 MB (`whisper-cli.exe` + DLLs under `resources/whisper/bin/win-x64/`).

## Projects & Navigation

- **My Projects — cards or list:** Toggle layout on the workspace home; preference is remembered on this device. *Use case:* compact overview when you have many projects.*
- **Project switcher:** New projects appear in the header dropdown immediately — no restart. *Use case:* create and switch in one session.*
- **Dashboard administration:** Assets and attachments show **In use** / **Unused**, linked notes, and readable attachment names. *Use case:* clean up unused files safely.*
- **Canvas preview:** World canvas preview on the dashboard reloads only on demand; can be saved as project card cover. *Use case:* stable thumbnail until you choose to refresh.*
- **Views thumbnails & order:** Saved views and bookmarks get preview images; new views sort newest first; drag or menu to reorder. Recently used chips for quick access. *Use case:* find the view you need without scrolling folders.*
- **Achievements:** Milestones for notes, connections, exports, focus mode, and more — celebration overlay with confetti (respects reduced motion). Trophy room in app settings. *Use case:* gentle feedback as your project grows.*
- **Focus music:** Ambient tracks in immersive focus mode — play/pause from toolbar or mini widget; separate volume from UI sounds. *Use case:* deep work without leaving the app.*
- **Smarter search everywhere:** Command palette and title-bar search use relevance ranking across title, summary, and content. *Use case:* find notes by meaning, not just by edit date.*
- **Setup wizard — usage profile:** On first launch (or manually from **App settings**), pick a profile (**Balanced**, **PKM**, **Worldbuilding**, **Software & documentation**). Navigation, compact icon bar, and startup destination are preset accordingly — change anytime under **Navigation**. *Use case:* sensible default modules without a long configuration session.*
- **Starter templates on create project:** Bundled templates **GDD**, **Zettelkasten**, and **Sprint & Kanban** appear under **Create project → Choose template** (alongside **Blank canvas**); you can also import your own `.db`. *Use case:* jump into a matching use case quickly — e.g. PKM roles or a sprint board with demo content.*
