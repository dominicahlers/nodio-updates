# Nodio 0.6.1

**Ausgabedatum:** Juni 2026

Hotfix **0.6.1** behebt einen Fehler im Auto-Updater, durch den Beta-Nutzer fälschlich eine ältere Stable-Version als Update angeboten bekamen.

---

## Bugfixes

- **Auto-Updater — kein Downgrade mehr:** Wenn der Beta-Kanal aktiv ist und auf GitHub kein passendes Beta-Release existiert, fiel electron-updater auf `latest.yml` (Stable) zurück und bot eine **ältere** Version (z. B. 0.5.0) als Update an. Ursache: Der `channel`-Setter von electron-updater setzt intern `allowDowngrade = true`. Nodio setzt das jetzt explizit auf `false`. Zusätzlich ignoriert der `update-available`-Handler Feed-Versionen, die nicht semver-neuer als die installierte App sind.
- **Technik:** [`updateService.ts`](../../00__Phase_Source/src/main/services/updateService.ts) — `applyUpdaterChannelSettings()` + semver-Guard im Event-Handler.

---

## Hinweis für Beta-Nutzer

Damit der Updater künftig auch **neue** Beta-Builds findet, muss das Release auf GitHub (`dominicahlers/nodio-updates`) mit `beta.yml` deployt werden — z. B. via `scripts/01__Windows/phase-deploy-beta.ps1`.
